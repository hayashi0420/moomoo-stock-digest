# moomoo ニュース解読 Stock Digest Skill

moomoo ニュース検索 API を直接呼び出し、指定した単一銘柄・企業に関する最新公開ニュースを取得して、主要イベントを抽出し、影響方向(強気・弱気・中立)を判定した上で、構造化されたストックダイジェストを証拠リンク付きで出力する Claude Code 用 Skill です。

## 機能概要

- 指定銘柄(1 件)に関する最新ニュースを取得
- 各ニュースから主要イベントを抽出
- イベントごとの影響方向(強気・弱気・中立)を判定
- 元ニュースへの証拠リンクを添付
- 非投資勧誘免責事項を付与した構造化レポートを出力

## 想定ユースケース

- 特定銘柄の最新ニュースを一括把握したい
- ニュースが強材料か弱材料かを素早く判断したい
- 投資判断前の情報整理を行いたい
- 複数ソースのニュースを構造化して比較したい

## 必要環境

- Claude Code CLI または Claude Agent SDK
- moomoo OpenAPI 認証設定済み環境
- curl / openssl / date コマンド(Linux・macOS 標準搭載、Windows は Git Bash 推奨)
